# Contributing

Thanks for your interest in contributing.

## Getting Started

1. Fork the repository
2. Clone your fork
3. Install dependencies: `pnpm install`
4. Start the dev server: `pnpm dev`

## Development

- **Lint:** `pnpm lint`
- **Format:** `pnpm fmt`
- **Type check:** `pnpm astro check`
- **Build:** `pnpm build`

## Submitting a Change

1. Create a branch from `main`
2. Make your changes
3. Run lint, format, and type check before committing
4. Open a pull request using the provided PR template
5. Reference the related issue in your PR

## Commit Messages

This project follows [Conventional Commits](https://www.conventionalcommits.org). Use prefixes like `feat:`, `fix:`, `chore:`, `docs:`, `style:`, `refactor:`.

## Code Style

- Use the existing formatter (oxfmt) and linter (oxlint)
- Match the style of surrounding code
- See `STYLE.md` for design principles
