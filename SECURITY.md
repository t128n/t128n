# Security Policy

## Reporting a Vulnerability

This site is a static Astro site with no server-side logic, user input handling, or authentication. The attack surface is minimal.

If you believe you have found a security issue, please report it through [GitHub's private vulnerability reporting](https://github.com/t128n/t128n/security/advisories/new). Do not open a public issue.

## What to expect

I will acknowledge your report within 7 days. For a static site, most findings will have low practical impact, but I will still address valid issues promptly.
